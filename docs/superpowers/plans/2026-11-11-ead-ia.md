# EAD etapa 9 (criar curso com IA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Botão "Criar curso com IA" no painel: roteiro proposto pela IA, ajustado pela pessoa, e módulos escritos em segundo plano, tudo em rascunho.

**Architecture:** O código fica dividido em quatro partes:
- **Esquemas:** `src/lib/ead-ia-esquema.js` guarda os esquemas JSON enviados à API, a validação `zod` das respostas e do roteiro editado, e a conta de custo.
- **Gerador:** `src/lib/ead-ia.js` monta o pedido, chama o Claude (cliente injetado) e grava roteiro e módulos.
- **Fila:** `src/lib/ead-ia-fila.js` processa um passo por vez e retoma ao subir.
- **Painel:** as rotas ficam em `routes/ead.js`, e as telas em `views/admin/ead/ia-*.ejs` com o script `public/js/ead-ia.js`.

**Tech Stack:** Node 22 (CommonJS), Express 4, EJS, Prisma 5/Postgres, node:test, `@anthropic-ai/sdk` (novo), `mammoth` (novo), `zod` 3, `multer`.

**Spec:** `docs/superpowers/specs/2026-11-11-ead-ia.md`

## Global Constraints

- **Modelo e chamada:**
  - modelo `claude-opus-5-5`;
  - `client.beta.messages.stream({...})` + `await stream.finalMessage()`, com:
    - `max_tokens: 32000`;
    - `thinking: { type: 'adaptive' }`;
    - `output_config: { effort: 'high', format: { type: 'json_schema', schema } }`;
    - `betas: ['server-side-fallback-2026-07-01']`, `fallbacks: 'default'`.
- **Custo** (US$ por milhão de tokens): entrada 4, saída 20, leitura de cache 0,20, escrita de cache 5.
- **Teto mensal:**
  - chave `Configuracao` `ead-ia:teto-mensal-usd`, padrão 50, de 0 a 1000;
  - o "mês" é o mês corrente no horário do Rio.
- **Limites do pedido:**
  - tema de 5 a 300 caracteres; público até 200; observações até 2000;
  - módulos de 2 a 12 (padrão 6); tópicos por módulo de 1 a 6;
  - até 3 arquivos `.pdf`/`.docx`, com 20 MB no total; texto colado até 100 000.
- **Mensagens exatas:**
  - "Configure a chave da API da Anthropic (ANTHROPIC_API_KEY) no servidor.";
  - "O teto de gasto com IA deste mês (US$ X) foi atingido." (X com 2 casas);
  - "A IA recusou: <categoria>" (sem categoria: "A IA recusou o pedido.");
  - "O material não pôde ser lido: <mensagem da API>";
  - selo: "Gerado por IA — revise antes de validar".
- **Regras dos módulos gerados:**
  - tudo nasce em RASCUNHO, com `geradoPorIa: true`;
  - nada já existente no curso muda;
  - testes nunca chamam a API: o cliente é injetado (`{ cliente }`).
- **Painel:**
  - só DEV (rotas sob o `requireDev` do EAD);
  - POST com CSRF e auditoria;
  - sem JS em atributos (CSP).
- **Commits** terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` e `Claude-Session: https://claude.ai/code/session_01CfLp5MfEj2LNthwUowXT7T`.

## Review Focus

1. **Cancelar no meio de um módulo:** o módulo em andamento termina e é gravado; nenhum outro começa; a geração vira CANCELADA → teste na Task 4.
2. **Resposta da IA que passa no esquema JSON mas quebra as regras** (pergunta com 2 corretas ou nenhuma, tópico sem perguntas, decisão sem opção correta): erro do módulo, nada gravado → teste na Task 2.
3. **Roteiro editado com módulo final fora do fim, dois finais, módulo sem tópico ou 13 módulos:** recusa com mensagem, nada muda → teste na Task 2.
4. **Teto atingido no meio de uma geração:** ela termina; "Gerar outro roteiro" e uma geração nova são recusados → teste na Task 5.
5. **Servidor reinicia com um módulo `gerando`:** ao subir, ele volta a `pendente` e é refeito uma vez; os prontos não se repetem → teste na Task 4.

### Task 3: Gerador (`src/lib/ead-ia.js`)

**Files:**
- Create: `src/lib/ead-ia.js`
- Test: `test/ead-ia.test.js` (Postgres local, cliente falso)

**Interfaces:**
- Consumes: Task 2.
- Produces:
  - `REGRAS_SYSTEM: string`: as regras da spec §5.3, fixas.
  - `async prepararMaterial({ arquivos: [{ nome, mimetype, buffer }], texto }) → { materialTexto, materialPdfs: [{ nome, base64 }] }`:
    - `.docx` via `mammoth.extractRawText({ buffer })`;
    - texto colado por último, com o cabeçalho "Texto colado:".
  - `montarMensagens(geracao, pedidoDoPasso: string) → { system, messages }`:
    - `system: [{ type: 'text', text: REGRAS_SYSTEM, cache_control: { type: 'ephemeral' } }]`;
    - uma mensagem `user` com, nesta ordem:
      - cada PDF: `{ type: 'document', source: { type: 'base64', media_type: 'application/pdf', data } }`;
      - o `materialTexto` (bloco de texto);
      - `cache_control` no último bloco do material;
      - o `pedidoDoPasso`.
  - `async chamarClaude(cliente, { system, messages, schema }) → { json, usage }`, que lança `ErroIa(mensagem)`:
    - `stop_reason === 'refusal'` ⇒ "A IA recusou: <stop_details.category>";
    - `max_tokens` ⇒ "A resposta da IA ficou longa demais.";
    - `Anthropic.BadRequestError` com material ⇒ "O material não pôde ser lido: …";
    - JSON inválido ⇒ "A IA devolveu uma resposta fora do formato.".
  - `ehChaveConfigurada() → boolean` (`!!process.env.ANTHROPIC_API_KEY`) e `clientePadrao() → new Anthropic()`.
  - `async gastoDoMes() → number` e `async tetoMensal() → number`.
  - `async podeComecar(usuarioId) → { ok } | { ok: false, erro }`: chave, teto e geração em andamento da pessoa (status `ROTEIRO_GERANDO`, `ROTEIRO_PRONTO` ou `MODULOS_GERANDO`).
  - `async criarGeracao({ pedido, material, criadoPor }) → geracao`, com status `ROTEIRO_GERANDO`.
  - `async gerarRoteiro(geracaoId, { cliente }) → void`:
    - chama o Claude e valida;
    - grava `roteiro` e `ROTEIRO_PRONTO`, ou `ERRO_ROTEIRO` com `erro`;
    - soma o custo nos dois casos (quando houver `usage`).
  - `async confirmarRoteiro(geracaoId, roteiroEditado, atorId) → { ok } | { ok, erro }`:
    - valida;
    - curso novo: `criarCursoOnline` (etapa 5) e preço/parcelas no `CursoOnline`;
    - grava `roteiro`, `cursoOnlineId`, `modulos[]` (todos `pendente`) e `MODULOS_GERANDO`.
  - `async gerarModulo(geracaoId, ordem, { cliente }) → void`:
    - marca `gerando`, chama, valida;
    - grava o módulo numa transação (spec §5.5) e marca `pronto`;
    - em erro, marca `erro`;
    - soma o custo.
  - `async tentarDeNovo(geracaoId, ordem, atorId)`, `async cancelar(geracaoId, atorId)`.
  - Auditoria: `EAD_IA_PEDIU`, `EAD_IA_CONFIRMOU`, `EAD_IA_CANCELOU`, `EAD_IA_TENTOU_DE_NOVO`, `EAD_IA_MODULO_GERADO`.

  - `prepararMaterial`: o `.docx` da fixture vira texto com "cinco golpes"; o PDF vira base64; o texto colado entra.
  - `montarMensagens`:
    - PDFs antes do texto do material;

    - o pedido por último;
    - `system` idêntico entre duas chamadas.
  - `chamarClaude`:
    - envia `model: 'claude-opus-5-5'`, `thinking`, `output_config.effort: 'high'`, `format.type: 'json_schema'`, `fallbacks: 'default'` e o beta;
    - recusa `{ stop_reason: 'refusal', stop_details: { category: 'bio' } }` ⇒ "A IA recusou: bio";
