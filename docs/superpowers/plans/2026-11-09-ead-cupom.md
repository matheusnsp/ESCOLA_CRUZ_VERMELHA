# EAD etapa 7 (Meus cursos online, cupom, parcelamento) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cupom de desconto e parcelamento no cartão na compra do curso online, e a aba "Cursos online" na Minha conta.

**Architecture:** As regras do cupom ficam em `src/lib/ead-cupom.js` (tabelas novas `CupomEad` e `CupomMatriculaEad`). A compra
(`routes/ead-online.js`) aplica o cupom no `valorCurso` da matrícula. O cartão do online (`routes/cursos.js` +
`lib/cobranca-avista.js`) passa a aceitar de 1 a `CursoOnline.maxParcelas` parcelas, pelo caminho do presencial
parcelado. A Minha conta ganha `sec=online`, montada por `src/lib/ead-meus-cursos.js`.

**Tech Stack:** Node 22, Express 4, EJS, Prisma 5/Postgres, node:test (`npm test`, concorrência 1).

**Spec:** `docs/superpowers/specs/2026-11-09-ead-cupom.md`

## Global Constraints

- Migração só acrescenta: nada em `Matricula` nem nos enums; `scripts/checar-migracao-ead.js` passa (tabelas novas em `TABELAS_EAD`).
- Painel do EAD só para contas DEV (o roteador `routes/ead.js` já filtra); POSTs com CSRF e auditados (`auditar(req, ACAO, alvo, id, dados)`).
- CSP: nada de JS inline em atributos; confirmação por `data-confirmar`.
- Testes nunca chamam o Únicopag de verdade: trocar `unicopag.criarTransacao` / `unicopag.obterOpcaoParcelamento` por falsos, como em `test/ead-online.test.js`.
- Código do cupom: maiúsculas, 3 a 30 caracteres de `A-Z`, `0-9` e `-`.
- Mensagens exatas: "Cupom não encontrado." · "Este cupom não vale para este curso." · "Este cupom venceu." · "Este cupom já foi usado o número máximo de vezes."
- `maxParcelas`: 1 a 12, padrão 1.

## Review Focus

1. QR de PIX reaproveitado (janela de 30 min em `iniciarCobrancaAVista`) depois de aplicar ou tirar o cupom: o aluno precisa receber um QR com o valor NOVO, não o antigo → teste na Task 3.

4. Duplo clique em "Liberar curso" (100%): uma matrícula, um `CupomMatriculaEad`, um registro de auditoria → teste na Task 3.
5. Preço do curso mudado no painel entre a capa e a compra: a compra recalcula o desconto sobre o preço atual → teste na Task 3.

### Task 2: Regras do cupom (`src/lib/ead-cupom.js`)

**Files:**
- Create: `src/lib/ead-cupom.js`

**Interfaces:**
- Produces:
  - `normalizarCodigo(texto: string) → string` — sem espaços (inclusive no meio), maiúsculas.

  - `calcularDesconto(cupom, preco: number) → { precoCheio, desconto, precoFinal }` — PERCENTUAL `round2(preco × valor ÷ 100)`; VALOR `valor`; desconto limitado a `preco`; `round2 = Math.round(x*100)/100`.
  - `async validarCupom(codigo: string, co: { id, precoOnline }) → { cupom, precoCheio, desconto, precoFinal } | { erro: string }` — ordem das checagens: inexistente/inativo, curso, validade (`validoAte` é o fim do dia no Rio: comparar com `fimDoDiaRio(validoAte)`), esgotado (`usosDoCupom >= limiteUsos`).
  - `async usosDoCupom(cupomId) → number` — `CupomMatriculaEad` com `matricula.statusPagamento in ['PAGO','PARCELADO']`.
  - `async criarCupom(dados, atorId) → { cupom } | { erro }` e `async alterarCupom(id, dados, atorId) → { cupom } | { erro }`. `dados = { codigo, tipo, valor, cursoOnlineId|null, validoAte|null, limiteUsos|null, observacao }`. Erros:
    - "Código: 3 a 30 letras, números ou hífen.";
    - "Já existe um cupom com esse código.";
    - "Desconto em %: de 1 a 100." / "Desconto em R$: maior que zero.";
    - "Limite de usos: 1 ou mais.";
    - na alteração com compra registrada, mudar código ou tipo ⇒ "Este cupom já foi usado: o código e o tipo não mudam.".
  - `async ativarCupom(id, ativo: boolean, atorId)`, `async apagarCupom(id, atorId) → { ok } | { erro: 'Este cupom já foi usado e não pode ser apagado.' }`.
  - `async listarCupons({ ativos?: boolean }) → [{ ...cupom, curso: nome|null, usos, totalDesconto }]` — `totalDesconto` soma `desconto` das compras pagas.
  - `async comprasDoCupom(id) → [{ aluno: { nome, email }, curso, data, precoCheio, desconto, precoFinal, situacao }]`.
  - Auditoria (`lib/auditoria` como em `ead-lote.js`): `EAD_CUPOM_CRIADO`, `EAD_CUPOM_ALTERADO`, `EAD_CUPOM_ATIVADO`, `EAD_CUPOM_DESATIVADO`, `EAD_CUPOM_APAGADO`.
